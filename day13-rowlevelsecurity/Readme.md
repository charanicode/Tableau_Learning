# Day 13 - Tableau Row-Level Security

## Overview
This project focuses on learning Row-Level Security (RLS) in Tableau and understanding how to publish a Tableau workbook.

## Topics Covered
- Understanding Row-Level Security in Tableau
- Learning how data access can be restricted based on user permissions
- Publishing a Tableau workbook
- Understanding secure data access in dashboards

## Tools Used
- Tableau
- Tableau Public / Tableau Server (depending on the publishing platform used)

## Project File
- `day14-rowlevelsecurity.twb` — Tableau workbook containing the project.

## Learning Outcome
Learned the basics of Row-Level Security and how to publish a Tableau workbook.
