# 📊 Day 8: Data Cleaning, Joins & Unions Using Tableau Prep Builder

## 🎯 Overview

As part of my Tableau Learning Journey, I worked with Tableau Prep Builder to practice data cleaning, transformation, and data integration. This hands-on exercise helped me understand how to prepare raw data for further analysis.

## 🛠️ Tools Used

- Tableau Prep Builder
- GitHub

## ✅ Activities Completed

### 1. Data Cleaning and Transformation
- Renamed fields to make column names clearer and easier to understand.
- Changed data types to ensure fields used the appropriate formats.
- Filtered unwanted rows to retain relevant records for analysis.

### 2. Joining Datasets
- Combined datasets using join operations.
- Explored how related datasets can be connected through common fields.
- Practiced integrating information from multiple tables.

### 3. Unioning Datasets
- Combined datasets by stacking rows.
- Learned how unions help consolidate data with similar structures.
- Understood the difference between joins and unions.

### 4. Workflow Creation
- Built a data preparation workflow in Tableau Prep Builder.
- Connected data preparation steps to organize the cleaning and transformation process.
- Prepared the resulting dataset for output.



## 📚 Key Learnings

- Understood the importance of data cleaning before analysis.
- Practiced renaming fields and changing data types.
- Learned to filter unwanted records.
- Explored joins and unions for combining datasets.
- Gained hands-on experience creating data preparation workflows.
- Understood how to prepare data for downstream analysis.

Gained practical experience in data cleaning, transformation, and data integration using Tableau Prep Builder. This exercise strengthened my understanding of preparing structured, analysis-ready data.
