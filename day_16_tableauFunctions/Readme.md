# 📊 Tableau Learning Journey – Day 16: Tableau Functions

## 📌 Overview
Today I learned and practiced different functions in Tableau using the Adventure Works dataset. I explored how functions help perform calculations, summarize data, manipulate text, extract date information, and apply logical conditions.

## 📚 Topics Covered

### 1. Aggregate Functions
- SUM() – Calculates the total of values.
- AVG() – Calculates the average.
- MIN() – Returns the minimum value.
- MAX() – Returns the maximum value.
- COUNT() – Counts records.
- COUNTD() – Counts distinct values.

### 2. Logical Functions
- IF – THEN – ELSE
- ELSEIF
- Conditional calculations
- Categorizing sales into High, Medium, and Low.

### 3. Date Functions
- YEAR() – Extracts the year.
- MONTH() – Extracts the month.
- DAY() – Extracts the day.
- Date subtraction – Calculates the difference between dates.

### 4. String Functions
- UPPER() – Converts text into uppercase.
- LOWER() – Converts text into lowercase.
- LEN() – Counts characters.
- CONTAINS() – Checks whether text contains a specific string.
- ENDSWITH() – Checks whether text ends with specified characters.

## 🛠️ Practical Implementation

- Calculated total profit and average discount.
- Identified maximum quantity and minimum sales.
- Counted unique countries and customer records.
- Categorized sales based on different conditions.
- Extracted month, year, and day from order dates.
- Performed date calculations using Order Date and Ship Date.
- Practiced text manipulation using customer names.
