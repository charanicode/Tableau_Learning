# 🏥 Healthcare Data Analysis Dashboard | Tableau

## 📌 Project Overview

This project focuses on analyzing healthcare data using Tableau to understand patient demographics, insurance providers, medical conditions, healthcare expenses, and patient hospital stay patterns.

An interactive dashboard was developed to transform raw healthcare data into meaningful insights that can support data-driven decision-making.

## 🎯 Project Objectives

- Analyze patient demographics across different age groups.
- Understand patient distribution by insurance provider.
- Compare healthcare expenses across insurance providers.
- Analyze medical expenses associated with different medical conditions.
- Evaluate average hospital length of stay by medical condition.
- Present key performance indicators through an interactive dashboard.

## 🛠️ Tools & Technologies

- Tableau – Data Visualization and Dashboard Development
- Microsoft Excel – Dataset Management
- Data Analytics – Data Exploration and Analysis

## 📊 Dashboard Components

The dashboard consists of six worksheets:

1. **KPI Overview** – Displays important healthcare performance indicators.
2. **Patients Count by Age Group** – Analyzes patient distribution across age groups.
3. **Patients by Insurance Company** – Shows patient distribution across insurance providers.
4. **Amount by Insurance Provider** – Compares healthcare expenses by insurance provider.
5. **Amount by Medical Condition** – Analyzes expenses associated with different medical conditions.
6. **Average Length of Stay by Condition** – Evaluates the average hospital stay across medical conditions.
